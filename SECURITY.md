# Security policy

AI Usage Widget reads local sign-ins for Claude Code, the Codex CLI and the Antigravity CLI. If you find a way it could leak a token, read more than it needs, or be abused by another program, please report it privately.

**Report a vulnerability:** use GitHub's [private vulnerability reporting](https://github.com/Marioarttv/AIUsageWidget/security/advisories/new). Please don't open a public issue for security problems.

Include what you found, how to reproduce it, and which version and OS you used. You should get a reply within a week. Fixes go into the next release; only the latest release is supported.
